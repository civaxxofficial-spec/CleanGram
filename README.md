# CleanGram

**Your space. Your rules.**

CleanGram is an independent, open-source Telegram client for Android and Windows.

## Platforms
- Android: Kotlin, Jetpack Compose, TDLib
- Windows: C#, WPF, TDLib

## Principles
- Privacy and transparency
- Customizable interface
- Advanced user profiles
- Light and dark themes
- Russian and English localization

CleanGram is an independent third-party project and is not affiliated with Telegram.
